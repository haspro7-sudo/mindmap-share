## 0. 旧作の振り返り（なぜ作り直すか）

| 旧作の要素 | 何が起きていたか | RE での扱い |
|---|---|---|
| 打／投／ガードの3すくみ | 表層は成立していたが「どの手を選ぶ理由」が薄く、意思決定が作業化 | **残す**。ただし辺ごとの報酬に差をつけ、間合いで意味を変える |
| 距離 ±3 と壁 | 距離はマトリクスの副産物で、プレイヤーが**能動的に**動かせなかった | **移動を手にする**（前進／後退）。間合いが読み合いの主役 |
| Excel 由来のダメージ表 | 数値の根拠が「表」で、なぜその値かが説明できない | **1拍の解決を手続きで定義**し、表はその結果として導出 |
| 必殺ゲージ（被弾で溜まる） | 逆転装置として良かった | **残す**。ただし「読み勝ち」でも溜まる通貨に拡張 |
| HP 7 / 2本先取 / 3秒タイマー | テンポは良かった | HP 6、2本先取、3秒タイマーを継承 |
| 膠着60ターン打ち切り | 「待ち」が最適になる状態が残っていた | **リング縮小**で待ちを構造的に禁止 |

旧作の最大の弱点は「読み合いが**1枚の表**で完結し、状況（間合い・壁・ゲージ）で読みの中身が変わらなかった」こと。RE は「**どこで戦うか**」を最初の読み合いにする。

## 1. コンセプト

**「間合いを制する者が、読み合いを制する。」**

- 3すくみ（打 > 投 > ガード > 打）は**密着でしか完全には成立しない**。
- 近距離では投げが「踏み込み」になり、中距離では打撃が「差し返し」になる。遠距離では前進しかない。
- だから毎拍の問いは「何を出すか」の前に「**今の間合いで何が届くか**」になる。
- リングは5拍ごとに狭まる。逃げ続ける選択は構造的に存在しない。

設計目標（数値で検証する）：

| 目標 | 指標 | 判定 |
|---|---|---|
| 公平 | 開始状態の均衡値 = 0 | `BALANCE.md §1` |
| 死に手がない | 全ての手が「5%以上選ばれる状態」を10%以上持つ | `BALANCE.md §5` |
| テンポ | 均衡自己対戦の平均ラウンド長 8〜15 拍 | `BALANCE.md §6` |
| 決着する | 時間切れ率 < 10%、引き分け率 < 10% | `BALANCE.md §6` |
| 逆転装置 | ゲージMAX状態の均衡値が +0.15〜+0.35（HP 1〜2 本分） | `BALANCE.md §4` |
| 壁の意味 | 壁際密着の均衡値が −0.05〜−0.25 | `BALANCE.md §3` |

## 2. 設計原則

1. **手続きで定義し、表は導出する。** 「移動 → 届く判定 → 優先順位」の3段階で全結果が決まる。表を暗記しなくても、理屈で結果が予想できる。
2. **全ての手に、勝つ相手と負ける相手がある。** 均衡ソルバーで死に手を検出し、あれば設計を直す。
3. **待ちは損。** 前進は受け身の相手からゲージを奪い、リングは狭まる。
4. **逆転はあるが、ただでは無い。** 必殺は強いが密着の投げに負け、空振りすればゲージを失う。
5. **画面で理屈が見える。** 間合いラベル、「届く/届かない」のヒント、カウンター・崩し・見切りの表示で、なぜそうなったかを必ず出す。

## 3. ルール正本

### 3.1 アリーナと間合い

- 直線のリング。座標は**半マス単位**で `0..18`（9マス幅）。
- 1P は左（右向き）、2P は右（左向き）。開始位置 1P=6、2P=12（**中距離**）。
- 距離 `d`（マス）= `(pos2 − pos1 − 2) / 2`。`d=0` が**密着**（隣接）。

| d | 間合い | 届く技 |
|---|---|---|
| 0 | 密着 | 打撃・投げ・必殺 |
| 1 | 近距離 | 打撃・必殺（投げは踏み込んで密着に入る） |
| 2 | 中距離 | 必殺のみ（打撃は空振り、投げは踏み込んで近距離へ） |
| 3+ | 遠距離 | 何も届かない |

### 3.2 手（Move）

毎拍、両者が同時に1つ選ぶ。選択は**ロック**（取り消し不可）、3秒で未選択はガード扱い。

| 手 | できること | 選べない条件 |
|---|---|---|
| 打撃 | d ≤ 1 で当たる。1ダメ | — |
| 投げ | d = 0 で成立。2ダメ + 相手を1マス押す。d = 1〜2 なら**踏み込んで**から判定 | — |
| ガード | 打撃を防ぐ | — |
| 前進 | 1マス詰める | 密着（d=0） |
| 後退 | 1マス下がる。**後退中は投げられない** | 壁際（背後に余白なし） |
| 必殺 | d ≤ 2 で当たる。3ダメ、ガード不能 | ゲージ < 5 |

### 3.3 1拍の解決手順

```
1. 移動      前進・後退・投げの踏み込みを同時に適用（壁でクランプ。互いに踏み込んで衝突したら半マスずつ進んで密着）
2. 届く判定  移動後の d で、各攻撃が届くかを判定（投げは相手が後退中なら届かない）
3. 優先順位  届いた技の組み合わせで被害を確定
   両方届いた：打 vs 打 = 相打ち（両者1、ただし相打ちでは KO しない）
              打 vs 投 = 打勝ち（投げ側カウンター2）
              打 vs 必 = 必殺がアーマーで通す（必殺側1、打撃側3）
              投 vs 投 = 投げ抜け（無効）
              投 vs 必 = 投げ勝ち（必殺側2 + 押し出し）
              必 vs 必 = 両者3
   片方だけ届いた：
              打撃 → ガード     = ガード成立。攻撃側に反撃1、攻撃側が1マス弾かれる
              打撃 → 前進/空振り = カウンター 2
              打撃 → 後退       = 通常ヒット 1
              投げ → ガード     = 崩し 3 + 押し出し
              投げ → それ以外    = 2 + 押し出し
              必殺 → 何でも      = 3（ガード不能）
   誰も届かない：
              空振り攻撃 vs ガード = ガード側ゲージ+1（見切り）
              投げ空振り vs 後退   = 後退側ゲージ+1（投げ抜け）
              前進 vs ガード/後退  = 前進側ゲージ+1（圧力）
4. 押し出し  投げ・ガード成立の押し出しは壁で止まる。投げで壁に押し付けられたら壁ドン +1
5. 拍を進め、5拍ごとに壁が1マスずつ迫る（最大3回）。壁の外にいたら押し込まれる
6. 決着判定  HP 0 で KO。24拍で HP の多い方が勝ち、同数は引き分け
```

### 3.4 ダメージ表（手続きから導出。自分の被害／相手の被害）

密着（d=0）：

| 自分＼相手 | 打撃 | 投げ | ガード | 後退 |
|---|---|---|---|---|
| **打撃** | 1 / 1（相打ち） | 0 / **2** | **1** / 0（弾かれる） | 0 / 1 |
| **投げ** | 2 / 0 | 0 / 0（抜け） | 0 / **3**（崩し） | 0 / 0（投げ抜け、相手+1G） |
| **ガード** | 0 / 1 | 3 / 0 | 0 / 0 | 0 / 0 |
| **後退** | 1 / 0 | 0 / 0（+1G） | 0 / 0 | 0 / 0 |

近距離（d=1）は投げが踏み込むため密着とほぼ同じだが、**前進**が加わる（打撃・投げに刺さるとカウンター）。
中距離（d=2）は打撃が空振りになり、前進・踏み込み投げに対する**差し返し**だけが打撃の役目になる。

### 3.5 ゲージと必殺

- ゲージ 0..5。ラウンドをまたいで**持ち越す**。
- 溜まる条件：被弾（1ダメージイベントにつき+1）／見切り／投げ抜け／圧力。
- 必殺：ゲージ5で選択可能。d ≤ 2、ガード不能、3ダメ。打撃をアーマーで受ける（自分は1ダメ）。**密着の投げには負ける**。空振りでもゲージは消費。

### 3.6 ラウンド・試合

- HP 6、2本先取。時間切れは24拍。
- リング縮小：5・10・15拍目で両側の壁が1マスずつ迫る（最終的に幅3マス = 最大でも中距離）。

## 4. 間合い別の読み合い構造

```
密着   打 > 投 > ガ > 打   （三すくみ完成形。後退は打撃に負けるが投げを抜ける）
近距離 打撃 ⟷ ガード の睨み合いに「踏み込み投げ」と「前進」が刺さる／刺される
中距離 ガード(待ち) ⟷ 前進(圧力+1) ⟷ 打撃(差し返し)  … 投げは踏み込みでガードを崩しに行ける
遠距離 前進のみ（構造的に待てない：リングが迫る）
壁際   後退が消え、投げに壁ドンが乗る → 密着の三すくみが加速
ゲージMAX 必殺が第4の手として加わり、相手は「投げで潰す」か「後退で外す」かを迫られる
```

均衡ソルバーの出力（`BALANCE.md §2`）で、各間合いの混合戦略がこの構造どおりになっているかを確認する。

## 5. CPU 設計

全難易度を**同じ骨格**（行列ゲームの均衡）で作り、強さは「先読み深さ」と「相手モデル」で差をつける。

| 難易度 | 方式 | 狙い |
|---|---|---|
| Easy | 選べる手から一様ランダム | 初心者が理屈を試せる |
| Normal | 1手先の状態を評価関数で採点し、行列ゲームの**混合均衡**を引く。4割の拍で相手モデルを軽く使う | ほぼ搾取されず、露骨な連打は咎める |
| Hard | 2手先読み + **相手モデル**（間合い別の手の出現率、指数減衰）。均衡と観測を混ぜた相手分布に最適応答 | 人間の手癖を狩る |

均衡は `src/engine/lp.ts` の単体法で厳密に解く（6×6 以下なので数十マイクロ秒）。
評価関数は `HP差 × 0.8/6 + ゲージ差 × 0.05 + 余白差 × 0.02`（`src/engine/cpu.ts`）。

## 6. バランス検証（手法）

`tools/solve.ts` は**全状態**（HP×位置×ゲージ×リング段階 = 約21万状態）について、
各状態の行列ゲームを LP で解きながら値関数を収束させる（Shapley 値反復、割引 0.97）。
リングが迫るタイミングは「毎拍 1/5 の確率」で近似する。

出力（`docs/BALANCE.md`）：
1. 開始状態の値（公平性）
2. 間合い別の均衡混合戦略
3. 壁際の値（壁を背負うコスト）
4. ゲージMAX時の値と戦略（逆転装置の強さ）
5. 死に手チェック
6. 均衡戦略どうしの自己対戦 2万ラウンド（ラウンド長・時間切れ・必殺頻度・手の使用率）

`tools/sim.ts` はゲーム内 CPU どうしを戦わせ、Hard > Normal > Easy の序列と、単純戦略（打撃連打など）を確実に狩れることを確認する。

### 6.1 設計の反復記録（数値は BALANCE.md の該当版）

| 版 | 変更 | 均衡自己対戦の結果 | 判断 |
|---|---|---|---|
| RE-1 | 5手+必殺、ゲージ3、釣り/圧力あり | 平均19.2拍、時間切れ42%、引き分け33% | 中距離ガード78%・近距離後退53%。待ちが最適 |
| RE-2 | **リング縮小**、前進がガードからも圧力+1、後退の釣り報酬を廃止 | 平均13.2拍、時間切れ1%、引き分け25% | 引き分けは相打ちダブルKO。必殺が1.6回/R で多い |
| RE-3 | 打撃同士を「相殺」に | 平均22.4拍、時間切れ68% | **失敗**。減りが無くなり待ちに戻る |
| RE-4 | 相打ちを戻し「相打ちでは KO しない」、崩し投げ 3、ゲージ 5 | 平均18.7拍、時間切れ38%、引き分け40% | 打撃偏重（密着76%）。ガード>打撃 の辺が弱い |
| RE-5 | **ガード成立で攻撃側に反撃1・攻撃側が弾かれる**、ガードのゲージ報酬廃止 | 平均15.9拍、時間切れ7%、引き分け9%、投げ13%、必殺0.86回/R | 三すくみの3辺に 1 / 2 / 3 の報酬差。全目標に届く |
| RE-6 | リング縮小を 5 拍ごとに | **平均15.1拍、時間切れ6%、引き分け9%、必殺0.82回/R、壁コスト −0.12、ゲージMAX +0.27** | 採用（現行） |

## 7. 演出・UI

- 論理解像度 960×540、CSS でフィット。棒人間はプロシージャル（関節角のポーズを補間）。
- 1拍の演出は**イベント列**（`BeatEvent`）から組み立てる：移動 0.25s → 打撃 0.4s / 投げ 0.6s / 必殺 0.55s で衝撃 → 押し出し → リング縮小。
- 衝撃の手触り：ヒットストップ（40〜160ms）、画面揺れ、パーティクル、必殺はスローと暗転。
- 必ず理由を表示する：`COUNTER!` `崩し!` `反撃` `GUARD` `見切り +1` `圧力 +1` `投げ抜け!` `壁ドン!` `相打ち` `空振り`。
- 選択中は中央に **間合いラベルとヒント**（例「中距離 · 打✕ 投→踏み込み」）を出し、ルールを画面で教える。
- HUD：HP 6セグメント、ゲージ 5 ピップ（MAX で金色 + SUPER READY）、拍数、壁までの拍数。
- 入力：1P `Q後 W必 E前 / A打 S投 Dガ`、2P `U前 I必 O後 / J打 K投 Lガ`。画面ボタン（マウス／タッチ）でも可。
- 音：WebAudio 合成（アセット無し）。`M` でミュート。

## 11. 未決事項（レビューで意見が欲しい点）

1. 投げの選択率が均衡で 5〜10% と低め。崩し 3 でも足りなければ「投げ成立でゲージ+1」か「打撃のカウンターを投げに対してだけ 1 に」のどちらが良いか。
2. 「相打ちでは KO しない」は説明コストがある。代替案は HP を 12 に倍化して相打ちを 1（半分）にすること。
3. ゲージ持ち越しは 2 ラウンド目の開始を「両者 SUPER READY」にしがち。ラウンド開始時に上限 3 へ丸めるべきか。
4. リング縮小の予告（壁まで N 拍）は十分か。壁が迫る拍は選択時間を 4 秒にするか。
