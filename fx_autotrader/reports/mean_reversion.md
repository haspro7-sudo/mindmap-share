再現: `python scripts/research_mean_reversion.py`（最終表を出力）／ 探索の各段階は `--stage 1..6`

## 1. 結論

* **判定: marginal（弱い証拠のみ。単独での実弾運用は推奨しない）**
* H1・H4 の逆張りは全滅。H4 はコスト前（ミッド価格）でもマイナスで、短期は「戻る」より「続く」相場だった。H1 は RSI(2) にコスト前 +0.03R 程度の戻りがあるが、スプレッド＋手数料（Blade 口座）で完全に消える。
* 唯一残ったのは **日足・主要5通貨ペア・ボリンジャー(20, 1.5σ)の再突入 + 3つのレンジ相場フィルター**。
  * IS（2005-2014）: Sharpe 0.70、CAGR 1.7%、最大DD 3.1%
  * OOS（2015-2020/05）: Sharpe 0.49、CAGR 1.1%、最大DD 4.6%
  * コスト2倍: IS Sharpe 0.61、OOS Sharpe 0.39
* ただし、次の点で採用基準を満たさない。
  * **Deflated Sharpe = 0.03**。102 試行を考慮すると、IS の成績は偶然と区別できない。
  * **FRED の 1976-2004 と 2020/05-2026/09 はどちらもマイナス**（Sharpe -0.04 / -0.06）。同じルールを OANDA の終値だけのデータ（FRED と同じ形）で 2005-2020 に適用すると、プラスが残る（Sharpe 0.53 / 0.82）。したがって「FRED が終値のみだから」では説明できず、効果は 2005-2016 頃に限られていた可能性が高い。
  * OOS の利益の大半は 2015-2016 年のもの（1トレード当たり純R +0.24）。2017-2020/05 は +0.02 でほぼゼロ。
  * 利益が小さすぎる。1%リスクで 2005-2020 の 15.4 年間に 50万円 → 約62.6万円（CAGR 1.5%）。1億円目標への寄与はほぼ無い。

## 3. 選定（IS のみ）

基準は「IS 取引数 ≥ 150 の中で Sharpe・MAR・t(R) による順位付け」。BB 1.5σ / majors5 が3指標すべてで1位になったため採用した。

ただし、t(R) は fx15 版（2.48）とほぼ同じ。majors5 の優位の多くは「取引数が少なく集中した結果」の可能性がある。そこで fx15 と all16 を近傍として OOS に回した。結果は下記の通りで、どちらも OOS でマイナスになった。

## 4. 最終ルール（MT5 EA で実装可能）

* **銘柄**: USDJPY, EURUSD, GBPUSD, AUDUSD, USDCAD
* **時間足**: D1（サーバー時間 = NY+7h、NY17時締め）
* **判定の基準**: 確定した日足（shift 1）
* **推奨執行時刻**: サーバー時間 01:00。00:00 のロールオーバーはスプレッドが数倍になるため避ける（下記「執行時刻チェック」）。

**インジケーター**（全て確定足の値）

* iBands(20, 1.5σ, 終値)。MT5 の iBands は母標準偏差で、検証コードと一致する。
* iADXWilder(14) のメインライン
* iATR(14)、iATR(100)
* 日足 iMA(200, EMA, 終値)、iATR(20)
* 日足 iMA(20, SMA, 終値)。BB の中心線と同じ。

**買いエントリー**（次の日足の始値で成行）。以下のすべてを満たすこと。

1. 2本前の終値 < 2本前の BB 下限、かつ 1本前の終値 > 1本前の BB 下限（バンド内への再突入）
2. ADX(14) < 25
3. ATR(14) / ATR(100) < 1.0
4. |終値 − EMA200| < 3.0 × ATR(20)
5. 終値 ≤ SMA20（出口条件をまだ満たしていない）

**売りエントリー**は完全に対称: 上限の外から内へ戻り、終値 ≥ SMA20。

**損切り**: エントリー価格 ∓ 2.5 × ATR(14)（シグナル足の値）。発注と同時に必ず設定する。利確指値は置かない。

**手仕舞い**（いずれか最初に来たもの）

* 買いは終値 > SMA20（売りは終値 < SMA20）になった次の日足始値
* 損切りに約定
* 保有 10 本目の日足が確定した次の始値（時間切れ）
* 反対方向のエントリー条件が成立したら決済してドテン

**ポジションサイズ**: 残高の 1% ÷（損切り幅＋スプレッド）で算出し、0.01 ロット単位で切り捨てる。

**同時保有の制限**: 同一銘柄は 1 ポジションまで。同時保有リスクは合計 8% まで。

**禁止事項**: ナンピン、グリッド、マーチンゲールは使わない。

### FRED の形式による影響の診断

FRED は終値しか無い（高値・安値が無い）。この形式のせいで結果が変わるのかを確かめるため、同じルールを OANDA 2005-2020 の終値だけで作った FRED 形式の日足に適用した。

* IS: Sharpe 0.535、75 取引
* OOS: Sharpe 0.820、49 取引

データ形式のせいで利益が消えるわけではない。**FRED 両期間のマイナスは、この効果が 2005-2016 頃に固有だった可能性を示す。**

* 不一致: **0**

## 8. 主なリスク

1. **多重検定**: 102 試行で DSR 0.03。IS の Sharpe 0.70 は探索の結果として説明できる範囲にある。
2. **効果の減衰**: 2017-2020 と FRED 2020-2026 はほぼゼロからマイナス。OOS のプラスは主に 2015-2016 年による。
3. **ユニバース選択の後知恵**: 主要5通貨は IS で選んだ。事前仮説のクロス通貨は外れ、クロスを含めると OOS でマイナスになる。
4. **取引が少ない**: 年約 20 回、IS 209 回。1 銘柄・数年の偶然で成績が大きく変わる。
5. **利益が小さい**: 1%リスクで年 1〜1.7%。意味のある額にするにはリスクを 3〜5 倍にする必要があり、DD もほぼ比例して増える（1%で最大DD 4.9%）。
6. **スワップ**: Titan FX のスワップのマークアップが実際はさらに悪いと、純R（OOS +0.08）はすぐに消える。
7. **ロールオーバー時のスプレッド**: 00:00 の執行はモデルより不利。01:00 執行を推奨する。

## 9. ユーザー向けのまとめ

* 「短期の行き過ぎを逆張りで取る」系の自動売買は、Titan FX Blade のコスト（スプレッド＋片道約3.5ドルの手数料＋スワップ）では、1時間足・4時間足で**期待値がマイナス**だった。いわゆるナイトスキャルも含む。
* 日足の主要通貨でわずかなプラスが見えたが、統計的に弱く、直近では消えている。**このファミリーを 50万円 → 1億円の主力にすることはできない**。
* 使うとしても、デモ口座での前向き検証（半年〜1年、実スプレッド・実スワップの記録）を経たうえで、他の戦略と組み合わせる小さな補助にとどめるべき。

## 10. 共通コードについての気付き（修正はしていない）

* `instruments.policy_rate` は 2005 年より前を 2005 年の値に固定する。FRED pre（1976-2004）のスワップは当時の金利差を反映しない。例えば 1980 年代の円金利は 0% として扱われる。
* 共通指標の `avg_R`、`t_stat_R`、`profit_factor_R` はスワップと手数料を含まない。本戦略では純Rより約 0.023R 高く出る（OOS t 値 1.77 → 純R では 1.37）。保有期間の長い戦略同士を比べると、順位を誤る可能性がある。
* コストモデルは全時間帯でスプレッドが一定。D1 戦略はすべて 00:00（ロールオーバー）の始値で約定するので、実際より有利に評価される。時間帯別スプレッドの導入か、D1 の約定を 01:00 にすることを推奨する。
* FRED モードでは、次の足の始値 = 前日終値。シグナルを出した足の終値そのもので約定する形になり、損切りも終値ベースでしか判定されない（data.py に記載済みの制約）。
