# carry_trend - キャリー＋トレンド保護（高金利通貨を買い、トレンドと変動率で身を守る）研究レポート

生成: `python scripts/research_carry_trend.py`（この表の数値はすべてスクリプト出力と同一。試行ログを再利用して最終表を出力し、`reports/equity/carry_trend.parquet` と `reports/trades/carry_trend.parquet` を書き出す。`--fresh` で IS 探索をやり直す）

## 結論

**判定: marginal（小さく、金利環境しだいで現れる優位性。統計的には未確定で、単独では 50万円→1億円 の目標には使えない）。**

* IS（2005-2014）で選んだ設定は Sharpe 0.49・CAGR 2.2%・最大DD 15.5%・198 取引・スワップ込み平均R 0.150（t = 1.82）。ただし 186 通りの試行を考慮した Deflated Sharpe Ratio は **0.0030**（試行 Sharpe の実測ばらつき 0.20 を使うと 0.417）で、IS だけでは偶然と区別できない。
* **OOS（2015-01〜2020-05）は取引ゼロ。** この期間は前年の政策金利差が 4% 以上の通貨ペアが1つも無かった（最大でも EURUSD -2.6%（2020年））。つまりこのルールは OOS では「何もしない」が正解で、損益の検証はできていない。しきい値を下げた近傍（min_diff=2.4）は OOS で 27 取引・平均R -0.053・Sharpe -0.17 とマイナスで、「金利差が小さいキャリーはブローカーのスワップ差（年2.5%）に負ける」ことと整合する。
* 真の未使用期間である **FRED 2020/05-2026/09** では 79 取引（2024〜2025年のみ稼働）・Sharpe 0.42・CAGR 1.9%・最大DD 9.4%・平均R 0.215（t = 1.74）とプラス。4銘柄（USDJPY, GBPJPY, AUDJPY, CADJPY の買い）すべてプラス、コスト2倍でもSharpe 0.39。2024年8月の円キャリー巻き戻しの前に全ポジションが決済済みだった。
* **FRED 1976-2004**（前年金利はモジュール内の近似表、後述）でも 913 取引・Sharpe 0.58・平均R 0.167（t = 3.59）。1970年代を除いても 869 取引・平均R 0.105（t = 2.61）で、5年ごとのブロックはすべてプラス。
* **キャリーの条件が本質**: 同じトレンド／変動率ルールを金利差を無視して両方向に使うと IS Sharpe -0.65・OOS -1.01・FRED OOS -1.42 と大きくマイナス（ベースラインのトレンドフォロー減衰と同じ）。一方トレンド条件を外した純キャリー（変動率フィルター・損切り・トレールは同じ）は IS 0.48・FRED OOS 0.71 と遜色なく、FRED 1976-2004 だけ 0.13 に落ちる。IS で効いているのはトレンド条件より「変動率が平常以下のときだけ入る」「2 ATR 損切り＋3 ATR トレール」の方。
* 弱点: (1) IS の利益の 72% が AUDJPY 1銘柄（採用基準5に抵触）、(2) 稼働するのは金利差が大きい年だけ（取引があった年: 2005, 2006, 2007, 2008, 2009, 2011, 2012, 2024, 2025）。2013〜2023年と **2026年（現在）は取引シグナルが一切出ない**（2025年平均金利で最大の差は GBPJPY +3.8%）、(3) 1%リスクでの CAGR は稼働年でも数%で、資金を増やすエンジンとしては小さすぎる。

## 戦略の定義（最終選択された設定）

| 項目 | 内容 |
|---|---|
| 銘柄 | 15通貨ペア（USDJPY, EURUSD, GBPUSD, AUDUSD, USDCAD, EURJPY, GBPJPY, AUDJPY, CADJPY, EURGBP, EURAUD, GBPAUD, EURCAD, AUDCAD, GBPCAD）。どのペアを取引するかは下の金利差ルールが毎年自動で決める（XAUUSD は対象外） |
| 時間足 | 日足（サーバー時間 NY+7h、NY17時締め）。判定は確定足の終値、発注は翌日 01:00（サーバー時間、ロールオーバー回避）。金曜のシグナルは月曜 01:00 |
| キャリー方向 | 金利差 = 基軸通貨の政策金利 − 決済通貨の政策金利。**前年**の年平均値を使う（当年の値は使わない）。金利差 ≥ +4% なら買いのみ、≤ −4% なら売りのみ、それ以外のペアはその年は取引しない |
| トレンド条件 | 買い: 終値 > EMA(50)、売り: 終値 < EMA(50)（MT5 iMA MODE_EMA、終値） |
| 変動率条件（エントリー） | σ20 / σ250 < 1。σN = 直近N本の日足終値の対数リターンの標準偏差（母集団ではなく標本標準偏差 ddof=1） |
| エントリー | 上の3条件（キャリー方向・トレンド一致・変動率）がすべて成立し、その銘柄にポジションが無ければ成行で建てる。決済後も条件が続いていれば翌日以降に再エントリー |
| 損切り（エントリー時に必ず設定） | エントリー価格 ∓ 2 × ATR(20)（MT5 iATR = 真の値幅の単純平均、日足） |
| トレーリング | 毎日の判定時（01:00）に 損切り = max(現在の損切り, エントリー後の最高値 − 3 × ATR(20))（売りは対称）。最高値はエントリー後の1時間足の高値で更新。利確なし |
| 決済 | 終値が EMA(50) の反対側に抜けた日、σ20/σ250 ≥ 1.5 の日、または年が替わってキャリー方向が変わった（しきい値未満になった）日の翌 01:00 に成行決済 |
| 資金管理 | 1トレードのリスク = 残高の1%（損切り幅×ロット）、0.01ロット単位で切り捨て（0.01ロット未満になる取引は見送り）、同一銘柄1ポジション、同時リスク合計8%まで |
| 使わないもの | ナンピン・グリッド・マーチンゲール・損切りなしのポジション・逆張りの「巻き戻し」売り（検証したが IS で悪化） |

政策金利は `fxlab/instruments.py` の年平均表（2025・2026年は推定値）。2005年の判定に必要な2004年以前の値は `fxlab/strategies/carry_trend.py` の `RATES_PRE`（中央銀行の政策金利履歴から丸めた近似値、精度 ±1%pt 程度、1985年以前の豪・NZ・スイスは ±2%pt）で、パラメータ選択には一切使っていない（FRED 1976-2004 の検証専用）。

## 探索の手順（IS 2005-2014 のみで選択）

* 試行数 **186**（すべて `reports/trials/carry_trend.jsonl` に記録）。IS Sharpe は中央値 0.29・標準偏差 0.20・プラスの割合 92%。順位付けは 1%リスクの日次損益の Sharpe、IS 取引数 150 未満は除外。
* 段階ごとの試行数: A 60, ABL 2, B 21, C 16, D 46, S0 1, bug_extra 40。
* Stage S0: モジュールの動作確認（金利差2.5%・EMA100・損切り4ATR）。1%リスク・50万円では円クロスの4ATR損切りが0.01ロットの最小単位を超えて多くが見送られるため、以降の損切りは2〜3ATRに限定。
* Stage A（60通り）: 金利差しきい値 1.0 / 2.5（ブローカーのスワップ差と同じ）/ 4.0% × トレンド条件（終値対EMA 50/100/200、EMA(n/4)対EMA(n) n=50/100/200、n日モメンタム 60/125/250、トレンド条件なし）× 損切り 2 / 3 ATR。変動率フィルターなし。
* Stage B（21通り）: トレンド系統の異なる上位3設定に変動率フィルター7種（σ20/σ250 の決済しきい値 1.5 / 2.0、エントリー上限 1.0 / 1.25、σ10 版、AUDJPY の変動率を全銘柄共通のリスクオフ指標にする版）。
* Stage C（16通り）: 上位2設定に EMA からの決済バッファー 0.5 / 1.0 ATR、3 ATR トレール、巻き戻し売り（リスクオフ時にキャリーと逆方向、20日/40日の時間切れ）、金利差上位3 / 6ペアに限定、円クロス5ペアだけの版。
* Stage D（プラトー検定）: 上位3候補の各パラメータを1つずつ動かした近傍（金利差 ×0.6/×1.4、EMA期間 ×0.67/×1.5、損切り ×0.75/×1.33、ATR 14、変動率しきい値 ×0.85/×1.2・決済なし、σ10、σ125、トレール ×0.75/×1.33）を IS で評価。
* 選択規則（OOS を見る前に固定）: 0.5 ×（本体の IS Sharpe ＋ 取引数150以上の近傍の IS Sharpe 中央値）が最大のもの。

## リスクと注意点

* **検証の空白**: 最終ルールは OOS 2015-2020 で一度も取引していない。未使用データでの損益の裏付けは FRED 2020/05- の79取引（2024〜2025年、t = 1.74）だけで、統計的に有意ではない。
* **金利表への依存**: キャリー方向は年平均の政策金利表で決まる。2025・2026年の値は推定、2004年以前は近似表。実運用では前年の実績（各国中銀の公表値）で毎年1月に更新すること。
* **エンジンのスワップ計算の簡略化**: スワップはエントリー年の金利差で保有期間全体を計算（年をまたぐ取引は IS 198 件中 8 件）。2005年より前は2005年の金利で計算されるため、FRED 1976-2004 のスワップ損益は実際と異なる（多くの場合、当時の実際の金利差より小さく、保守的）。価格ベースの平均Rでも同じ結論。
* **FRED データ**: 終値のみ（ニューヨーク正午レート）で、損切り判定はエンジンが作る合成ヒゲに依存。ATR はOANDAに合わせて0.68倍に補正（データ較正、成績では調整していない）。
* **集中**: IS の利益の 72% が AUDJPY。どの年も稼働は2〜4ペアで、すべて同じ「円（または米ドル）を売って高金利通貨を買う」リスク要因にさらされる。
* **少額口座の制約**: 50万円・1%リスク（5,000円）では、円クロスの損切り幅が約5円（500pips）を超えると0.01ロットでもリスク超過になり見送りになる。EA も同じ判定（最小ロット未満なら発注しない）にすること。
* **業者リスク**: スワップのマークアップ（年2.5%の想定）が変わると結論が変わる。マークアップが大きくなるほど、しきい値4%でも利益が薄くなる。

## 目標（50万円→1億円）への示唆

* 1%リスクでの成績は IS CAGR 2.2%、FRED 2020/05-2026/09 CAGR 1.9%、FRED 1976-2004 CAGR 4.3%。稼働した年の口座リターンは -9.5%〜+11.5% で、しかも10年以上何もしない期間がある。リスクを数倍に上げても、200倍（50万→1億）に必要な複利には遠く及ばない。
* 位置づけとしては「金利差が大きい時期だけ動く、小さな補助戦略」。他の戦略と組み合わせる場合も、配分は小さく、金利表の年次更新を前提にすること。
* 現在（2026年9月）はシグナルが出ない状態で、すぐに稼働する戦略ではない。

## MT5 EA 実装メモ

* 毎日、日足確定後の最初の 01:00（サーバー時間）に1回だけ判定・発注（ロールオーバー時間帯を避ける）。
* 各ペアについて: 前年の政策金利差（入力パラメータの年別表）→ キャリー方向。EMA(50) は iMA(PERIOD_D1, 50, 0, MODE_EMA, PRICE_CLOSE) の確定足（shift=1）値、ATR(20) は iATR(PERIOD_D1, 20) の shift=1 値、σN は shift=1 から N 本の日足終値の対数リターンの標本標準偏差を自前で計算。
* 注文時に損切りを必ず設定（価格 ∓ 2×ATR）。以後、毎日の判定時に 最高値（売りは最安値）− 3×ATR へ有利な方向にだけ動かす。
* ロット = 残高×1% ÷（損切り幅＋往復スプレッド）を円換算し 0.01 ロット単位で切り捨て。0.01 未満なら見送り。同時保有リスクが残高の8%を超える場合も見送り。
