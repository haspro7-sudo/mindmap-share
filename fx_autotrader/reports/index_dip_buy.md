## 1. 結論

* **判定: marginal（価格レベルの押し目効果は実在するが、CFDのコスト後はOOSでほぼゼロ。単独での実弾運用は推奨しない）**
* 選ばれたルール（ISのみで機械的に選択）: **日足・7指数・「終値が直近10本の最安値」かつ「終値 > SMA200」で買い、終値 > SMA10 で手仕舞い、最大20日、損切り 4×ATR(20)**。

* **Deflated Sharpe（IS, 186 試行）= 0.001**。IS の Sharpe 0.38 は試行回数を考えると偶然と区別できない。
* 採用基準との照合:
  1. DSR: 不合格（0.001）。
  2. IS 近傍の安定性: 合格（近傍の IS Sharpe 0.17〜0.46）。ただし OOS 近傍は -0.16〜+0.38 とばらつく。
  3. OOS の平均R > 0: かろうじて合格（+0.010R、t=0.39。ゼロと区別できない）。
  4. コスト2倍: **不合格**（OOS -0.018R、Sharpe -0.19）。
  5. 集中: **不合格気味**。利益は米国3指数（US500・NAS100・US2000）に集中し、欧州（FRA40・UK100）は OOS でマイナス、AUS200 は IS でマイナス。年別では 2017年 +14.4% と 2018年 -11.0% が突出。
* 規模: 1%リスク・4×ATR 損切りだと平均建玉は資金の **0.18倍**（保有中の日だけで 0.46倍、最大 1.59倍）、市場にいる日は 40%。15.4年で 50万円 → 約63.1万円。**1億円目標への寄与はない**。リスクを上げればリターンもDDも比例して増えるだけで、OOS の MAR は 0.01。
* **押し目効果そのものは本物らしい**（§6.1）。「10日安値」の翌日寄りから 5〜10日先のリターンは、上昇トレンド中の平均日より 0.05〜0.22 ATR 高い。これは IS・OOS・先物 1982-2004・先物 2020-2024 の全期間で成り立つ。ただし 4×ATR 損切りでは 0.03〜0.05R/トレードにしかならず、往復コスト（スプレッド＋スリッページ＋手数料＋スワップ ≈ 0.03〜0.04R）とほぼ同じ大きさ。**エッジは実在するがコストで消える**、というのが正直な結論。

## 2. 仮説とルール

株価指数は長期上昇トレンド中の短期の押し（RSI(2) の売られ過ぎ、N日連続安、終値がN日安値、ボリンジャー下限割れ、IBS）から数日で戻りやすい、という既知の効果（Connors ほか）。

**最終ルール（MQL5 実装用、ロングのみ）**

* 銘柄: US500, NAS100, US2000, JPN225, UK100, FRA40, AUS200（Titan FX の指数CFD）。時間足 D1（サーバー時間 GMT+2/+3、NY 17時締め）。
* 判定は確定した日足（shift 1）で行う。
  * トレンド条件: `Close[1] > iMA(D1, 200, SMA, CLOSE)[1]`
  * 押し目条件: `Close[1] <= min(Close[1..10])`（直近10本の確定終値の最安値。当日足を含む）
  * 同一銘柄のポジションが無いこと
* 発注: 次の日足が開いてから 60 分後（サーバー 01:00）の最初のティックで成行買い。UK100・FRA40 などその時刻に取引していない銘柄は、次に取引できる最初のティック（バックテストでは欧州の寄り付き）で約定。
* 損切り: 約定価格 − 4 × `iATR(D1, 20)[1]`（MT5 の iATR = 真の値幅の単純平均）。エントリー時に必ず設定し、トレールはしない。利確指値は置かない。
* ロット: 残高の 1% ÷（損切り幅 × 1ロット1ポイントの円価値）を lot_step で切り捨て。最小ロット未満なら見送る。
* 手仕舞い（毎日 01:00 の判定時に確認）:
  * `Close[1] > iMA(D1, 10, SMA, CLOSE)[1]` なら成行決済。
  * エントリー後 20 回目の日足判定で時間切れ決済。
  * 損切りは常時有効。
* 全銘柄合計の同時リスク上限は 8%。7銘柄×1%なので実際には上限に掛からない。

## 3. 検証手順（IS 2005-2014 のみで選択）

* ユニバースは事前に固定: 7指数すべて。金は最終ルールの確認のみで、ポートフォリオには入れない。
* 選択は機械的に行った。各段階で「近傍平滑化した IS Sharpe」が最大の設定を選ぶ（IS 取引数 ≥150 が条件）。
* **選択ルールの修正（開示）**
  * 最初に事前登録したルール v1 は「自分と両隣の平均」。これには端点のアーティファクトがあった。`down>=4`（自身の IS Sharpe 0.10）が、隣の `down>=3`（0.55）の山に引っ張られて 0.33 と評価され、選ばれた。
  * v1 の選択結果を OOS まで評価した後で、この欠陥に気付いた。そこで IS の論理だけで v2 = `min(自分, 自分と両隣の平均)` に直した（自分の成績を超えて評価されず、弱い近傍では減点される）。
  * v1 の選択（superseded）も隠さずに報告する: IS 0.10 / **OOS -0.42（-0.069R）** / pst_pre 0.29 / pst_oos 0.38。v1 の近傍 14 設定はすべて OOS マイナス（Sharpe -0.07〜-0.49）。
  * **注意**: ルール変更は v1 の OOS を見た後なので、v2 の OOS は完全に汚れていないとは言えない。2つの候補から選んだのに近いと考えてほしい。どちらも OOS はほぼゼロ以下で、結論は変わらない。
* 試行数: IS 186 設定（Stage A 38、B 69、C 15、E 9、D 4、F 24、近傍 26、診断 1）。

### Stage A: エントリーの種類（D1、出口 SMA5、最大10日、損切り 5×ATR20、38 試行）

5系統（RSI(2)/RSI(3)、N日連続安、IBS、ボリンジャー下限割れ、N日安値）× 閾値3〜6種 × トレンドフィルター{SMA200, なし}。

* 全38試行の IS Sharpe 平均: SMA200 あり 0.072 / なし 0.040 → **SMA200 フィルターを採用**。
* 系統ごとの v2 スコア（最良設定）:

| 系統 | v2スコア | 最良設定の IS Sharpe | 取引数 |
|---|---|---|---|
| nlow（N日安値） | 0.207 | nlow(10): 0.27 | 539 |
| bb | 0.170 | bb(10,1.5): 0.22 | 465 |
| rsi | 0.117 | rsi(3)<20: 0.16 | 397 |
| down | 0.082 | down>=3: 0.42（両隣は -0.07 / -0.10 で孤立した山） | 430 |
| ibs | -0.039 | ibs<0.1: 0.03 | 597 |

* **IBS は全く効かない**。24時間取引の CFD 日足（NY17時締め）の高安は現物指数の取引時間の高安と別物なので、文献の IBS 効果は再現しない。
* RSI(2)<10（Connors の定番）は IS Sharpe 0.12、平均R 0.014 と弱い。

### Stage B〜E（上位2系統 nlow・bb）

* B（出口7種＋時間のみ × 最大保有 5/10/20）: 両系統とも **終値 > SMA10、最大20日** が最良（nlow 0.36、bb 0.35）。「最初の陽線で手仕舞い」「前日高値超えで手仕舞い」は短すぎて劣る（nlow で 0.12〜0.25）。時間だけの出口も劣る。
* C（損切り 2/3/4/5/7/10 × ATR20）: nlow は 3〜7×ATR で Sharpe 0.36〜0.38 とほぼ平坦で、4×ATR（0.38）を選択。2×ATR は 0.28 で劣る（押しの途中で切られる）。bb は 10×ATR（0.38）。
* E（閾値の再確認、4×ATR）: nlow(5/7/10) = 0.10 / 0.28 / 0.38 → nlow(10) のまま。
* 最終比較: nlow 0.326 > bb 0.304 → **nlow(10)**。

### Stage D: 下降トレンド中の空売り（買われ過ぎの逆張り）

* nlow: ロング＋ショートの IS Sharpe 0.30（ロングのみは 0.38）。ショート単独は Sharpe -0.08、平均R -0.006、t=-0.25（202 取引）。
* v1 経路（down>=4）でもショート単独は -0.10。
* **ショートは何も足さない**ので不採用（事前基準: 合算 Sharpe が改善し、かつショート単独の t>1.5 なら採用）。

### Stage F: H4 版（D1 の SMA200 と D1 ATR 損切り、24 試行）

* IS Sharpe は -3.1〜-1.1 と全滅。
* 最良（nlow(10)、H4 出口 SMA10、最大30本）の1トレード当たり内訳: コスト前 +0.013R に対し、スプレッド＋スリッページ 0.019R、手数料 0.019R、スワップ 0.002R → 純 -0.026R。
* 保有が短くなって値幅が小さくなる一方、コストは同じ（損切りを D1 ATR にしたため R 当たりのコストは D1 版と同じ）。

## 7. リスクと注意点

* OOS のエッジはゼロと区別できない（t=0.39）。コスト2倍で OOS はマイナス。DSR 0.001。
* 選択ルールを v1 → v2 に修正したのは v1 の OOS を見た後（§3 に開示）。
* 利益は米国指数に集中し、年による振れが大きい（2017 +14.4%, 2018 -11.0%）。
* 指数CFDのコストモデルが未検証: 契約サイズ、最小ロット、手数料（JPN225 の異常）。配当調整は配当利回りを金利差に入れる近似で、トリプルスワップの曜日は水曜固定。
* 先物データ（pst）の検証は始値 = 前日終値なので、エントリーが信号の終値で約定する。欧州指数の CFD 約定（翌朝寄り）より有利。高安は合成レンジ。
* 50万円では最小ロット制約で見送りが出る（NAS100 の高ボラ期、UK100 の 2006-07 年）。
