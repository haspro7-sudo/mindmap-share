## 2. 共通定義（全ルール共通）

### 2.1 足と時刻

* M1 は `scalp.load(symbol)`。サーバー時刻は NY+7h なので、00:00 が NY 17:00（ロールオーバー）です。
* 上位足は `scalp.resample(m1, rule)`。rule は `'5min'`, `'15min'`, `'1h'`, `'4h'`, `'1D'`。ラベルはバーの始値時刻です。
* **FX の足の区切り**: サーバー時刻のままでよい。MT5（Titan）と、TradingView の OANDA 表示（NY 17:00 区切り）の両方と一致します。
* **BTC の足の区切り**:
  * EA の再現（R00）は、サーバー時刻で区切る（MT5 と同じ）。
  * やがみの裁量ルール（R08・R09 の 4h・6h・日足の陰陽）は、**UTC で区切る**。チェックリストの例「13時更新の4時間足」「15時の6時間足更新」は、UTC 区切り（JST 1,5,9,13,17,21 時）と一致します。
  * 作り方: `m1u = m1.set_axis(scalp.local_time(m1.index, "UTC"))` に元のサーバー時刻を列 `srv` として残し、NaT を落としてから resample します。各バーの最終 M1 の `srv` をシグナル時刻にします。
  * 6時間足は BTC だけで使います（UTC の 00/06/12/18 時）。
* 記号: 各足について O, H, L, C を使います。
  * R = H − L（値幅）
  * B = |C − O|（実体）
  * UW = H − max(O, C)（上ヒゲ）
  * LW = min(O, C) − L（下ヒゲ）
  * 陽線は C > O、陰線は C < O。
  * **十字線（クロス）は B/R < 0.2**（EA と同じ値）。

### 2.2 ATR

* A_k は、その時間足の ATR14 です。TR の**単純移動平均**（MT5 の iATR と Python 版に合わせる）で、バー k までの確定足だけを使います。
* **許容幅はすべて ATR の倍数で書き、価格の % では書きません**。EA と v2 の 2%・1.5%・0.5% は、FX では ATR の十数倍になり、条件として機能しません（第4章 B1・B4）。
* バー k 自身の形を判定する閾値（例: 大陽線かどうか）は A_{k−1} で測ります。自分自身を含めないためです。

### 2.3 確定スイング（押し安値・戻り高値）

* スイングローは、右側 n 本まで確定して初めて使えます。バー j がスイングローである条件は次のとおりです。
  * L_j < min(L_{j−n} … L_{j−1})（左は厳密に下回る）
  * かつ L_j ≤ min(L_{j+1} … L_{j+n})（右は同値を許す）
* **この事実を使えるのは、バー j+n の終値から**です。
* ベクトル化の形（時点 t で候補 j = t−n を判定）:
  * `L.shift(n) < L.rolling(n).min().shift(n+1)`
  * かつ `L.shift(n) <= L.rolling(n).min()`
  * 中心窓（`center=True`）は禁止です。
* スイングハイは、上の式で L → H、不等号を逆にしたものです。
* n の候補は {2, 3, 5} です。EA は n = 5 で、左右とも同値を許しています。
* 「最後の押し安値」: 時点 t で確定済みのスイングローのうち、最も新しく、かつエントリー価格より下にあるもの。

### 2.4 トレンド（2通り）

* **T-MA（EA 準拠）**: H1 の SMA12 と SMA48 を比べ、+1／−1／0 とします。使うのは確定した H1 足の値だけです。
* **T-Dow（チェックリスト準拠）**: H4 または D1 で、確定スイング（n = 3）の直近2つを見ます。
  * 高値も安値も切り上げていれば上昇（+1）。
  * 高値も安値も切り下げていれば下降（−1）。
  * それ以外はレンジ（0）。

### 2.5 シグナルから約定まで

* 判定は、シグナル足の終値の時点で行います。
* `scalp.signals_at_close(bars, frame)` を使い、次の M1 の始値で約定させます。
* sl と tp は pips で渡します。基準価格 P_ref（シグナル足の終値）からの距離です。
  * ロングなら sl_pips = (P_ref − SL価格) / pip。
  * BTC は 1 pip = 1 USD です。
* simulate は、SL/TP を**実際の約定価格**を基準に置き直します。そのため、スプレッドやギャップの分だけ水準がずれます（許容範囲。レポートに一言書く）。
* 上位足の値は、**閉じた足だけ**使います。時点 τ で使える H1 足は、終値時刻（始値 + 60分）が τ 以下のものです。`merge_asof` で結合し、キーは終値時刻にします。

### 2.6 状態で決まる決済（MA 交差、ヒゲ埋め、上位足の終値など）

* simulate が扱えるのは、固定の TP・SL・時間ストップだけです。
* 状態で決まる決済は、**決済の条件が確定する時刻**（その時刻までのデータだけで判定できる時刻）を先に計算し、`hold = その時刻 − 約定時刻`（分）として渡します。これは先読みではありません。
* 同じ取引に複数の決済条件があるときは、hold の最小値を使います。SL/TP はブローカー側で先に判定されます。

### 2.7 日次・週次の停止を重ねる場合

* 停止の判定には、**すでに決済済みの取引**の損益だけを使います（backtest_v3.py の先読みを繰り返さない）。
* 取引を1つ除くと、その間ふさがっていた時間に別のシグナルが入れるようになります。正確に扱うには、次を収束するまで繰り返します。
  1. シグナルを simulate する。
  2. 停止期間を求める。
  3. 停止期間のシグナルを除く。
* 数回で止まります。

### 2.8 評価の単位

* 主指標は net pips／回と R です。資金に対する % は、固定リスク（1%）で換算して補助的に示します。
* **勝率と期待値は必ず並べて**表示します。RR 3 の損益分岐勝率は 25% ＋コスト分、RR 1.5 なら 40% ＋コスト分です。

## 3. 原則ごとの仕様

凡例（検証可否）:
* ○ = OHLC で機械的に検証できる
* △ = 近似が必要、または結果がパラメータに強く依存する

パラメータ候補は IS で選ぶための格子です。**1ファミリーの総設定数は 50 程度まで**に抑えてください。

### R01 二番底／二番天井（一番底で入らない、15分足未満は不可）

* **原文**
  > 一番底/一番天井で入らない。「止まってから」エントリー。予測でエントリーしない。「どこで止まるか」ではなく「どこで止まったか」。15分未満の足の二番底は一切信用できない。
  > （ダブルボトム詳細）1発目につけたスパイクローを2回目のアタックで割らなかったらロング。但し、実体ベースでゆっくり降ってくる場合は売り押し目の可能性。1発目の強いリバが真上のレジスタンスに明確に弾かれた場合は、様子見かロットを落とす。
* **機械化**（ロング。ショートは上下を逆にする）
  * 時間足 TF ∈ {M15, H1, H4}（主は H1）。スイングの確定本数 n ∈ {3, 5}。
  * **S2（二番底）**: 時点 t で確定した最新のスイングロー。j2 ≤ t − n、価格は L2。
  * **S1（一番底）**: S2 より前の確定スイングロー。j1 は [j2 − Dmax, j2 − 5] の範囲。Dmax ∈ {40, 100} 本。
  * **水準の近さ**: −tol_brk·A ≤ L2 − L1 ≤ tol_up·A。A は j2 時点の ATR。
    * tol_brk ∈ {0, 0.25}。「割らなかったら」なので 0 が原文どおり。
    * tol_up ∈ {0.5, 1.0}。
  * **間の安値**: j1 と j2 の間に、L1 − tol_brk·A より安い安値がないこと。
  * **1発目のリバ**: ネックライン P = max(H_{j1..j2}) について、P − max(L1, L2) ≥ r_min·A。r_min ∈ {1.0, 2.0}。
  * **有効性**（時点 t で判定）:
    * j2 以降、L2 を割っていないこと（min L_{j2+1..t} > L2）。
    * エントリー方式 E1・E3 では、C_t < P（ネックラインの下で拾う）。
  * **エントリー方式**（候補。IS で1つ選ぶ）:
    * E1: S2 が確定した足（t = j2 + n）の終値。
    * E2: j2 から 20 本以内に、初めて C > P となった足（ネックライン抜け）。
    * E3: j2 以降 m ≤ 8 本以内に出た、最初の R03 クラス①〜③の陽線。
  * **除外（任意）**
    * 「実体ベースでゆっくり降ってくる」: P から L2 までの下落が k_desc ≥ 12 本以上かかり、その間の平均実体が 0.5·A 未満なら除外。
    * 「リバが上位足のレジに弾かれた」: P が上位足レジ（R10）の ±0.25·A_HTF 以内なら除外。
  * **SL**: min(L1, L2) − 0.1·A。**TP**: R13 に従う。
  * **トレンドの向き**: 上位足（T-Dow の H4/D1、または T-MA）と同じ向きのみ、という条件を候補にします。チェックリストは「順張りが基本」です。
  * **対照実験**（原則そのものの検証）
    * (a) 一番底で入る: どんなスイングローでも、確定した時点で同じ SL/TP で入る。
    * (b) M5 の二番底: 「15分未満は信用できない」の確認。
    * やがみが正しければ、(a) と (b) は本ルールより悪くなるはずです。
* **検証可否**: ○
* **先読みの注意**: S2 は n 本後にならないと分かりません。「底値そのもの」で入ることはできません。

### R02 横軸（止まった後に、時間が横に経過したか）

* **原文**
  > 価格が止まった後、横に時間が経過しているか。縦軸だけで判断しない。横軸 = 売り買いの攻防が均衡している証拠。待つ時間が一番大事。
* **機械化**
  * 止まった安値 L* をバー j とします（R01 の S2、または任意の確定スイングロー）。
  * 時点 t で次をすべて満たすとき「横軸あり」とします。
    * t − j ≥ h_min（h_min ∈ {4, 8, 12} 本）。
    * j から t まで、L* − 0.1·A を割る安値がない。
    * j から t までの終値の幅が w·A 以下（w ∈ {1.5, 2.5}）。
    * C_t ≥ L* + 0.25·A。
  * EA 版（参考）: M15 の直近12本の高値−安値が 1.5·ATR(M15) 以下。止まった安値とは結び付けていません。
* **使い方**: R01・R06 に対する「横軸あり／なし」の比較として検証します（単体の売買ルールにはしない）。
* **検証可否**: ○

### R03 ローソク足の強弱7種（エントリー足は③以上、④の連続はクソレンジ）

* **原文**
  > 強い順: ①大陽線 > ②中陽線 > ③前回陰線を包む陽線 > ④上下髭中ピンバー陽線 > ⑤下髭陽線 > ⑥ピンバー強陽線 > ⑦売り押し目の陽線。エントリー足は③以上が望ましい。④が上位足（日足/4h）で4本以上連続 → トレンドレスのクソレンジ → ポジション撤収。⑦はモブ。
* **機械化**（陽線のみ。ショートは陰陽を逆にする）
  * A = A_{t−1}。判定は次の順で行い、最初に当てはまったクラスを採用します（重なりをなくすため）。

| クラス | 条件 |
|---|---|
| ①大陽線 | B ≥ big·A かつ B/R ≥ 0.6（big ∈ {1.0, 1.5}） |
| ②中陽線 | 0.6·A ≤ B < big·A かつ B/R ≥ 0.5 |
| ③包み陽線 | 前の足が陰線で、C ≥ O_{t−1} かつ O ≤ C_{t−1}（実体で包む） |
| ⑥ピンバー強陽線 | LW ≥ 2B かつ LW ≥ 0.6R |
| ⑤下髭陽線 | LW ≥ B かつ LW ≥ 2·UW |
| ④上下髭中ピンバー陽線 | B/R ≤ 0.35、UW ≥ 0.25R、LW ≥ 0.25R |
| ⑦売り押し目の陽線 | B < 0.6·A、かつ下降の文脈（T-Dow = −1、または C < SMA48） |
| その他 | 上のどれでもない陽線 |

  * **エントリー条件**: クラス ∈ {①, ②, ③}。
  * **クソレンジ**: H4 または D1 で、「B/R ≤ 0.35 かつ上下のヒゲがともに 0.25R 以上」の足（色は問わない）が4本以上続いたら、レンジ状態とします。
    * レンジ状態の間は、トレンド方向の新規エントリーをしない。
    * 保有中なら、次の足の始値で決済する。
    * ①か②の足が出たら解除する。
* **原則そのものの検証（事象研究）**
  * トレンドが上向きの局面で、クラスごとに次を測ります。
    * 次の1本・4本の終値リターン（ATR 単位）
    * 次の足が陽線になる確率
  * IS で順位を確かめ、OOS で同じ順位が保たれるかを見ます。
  * やがみの主張は「① > ② > … > ⑦ の単調な順位」です。
* **検証可否**: ○

### R04 プライスアクション7種（チェックリストの「PA一覧」）

* **原文**: ロング寄り7種は次のとおりです。
  * 大陽線
  * 安値圏でのピンバー
  * 安値圏での下髭陽線
  * リバーサルロー（最強。ほぼ安値確定）
  * 一定の価格以下の下髭（実体の確定位置が揃う）
  * 無限スラストアップ
  * 上髭埋めムーブ
* **機械化**
  * 「安値圏」: L_t ≤ min(L_{t−N..t−1}) + 0.25·A（N ∈ {20, 50}）。
  * **ピンバー**: R03 の⑥（色は問わない）。安値圏で出たもの。
  * **下髭陽線**: R03 の⑤。安値圏で出たもの。
  * **リバーサルロー**: L_t < min(L_{t−N..t−1})（N 本ぶりの安値更新）、かつ C_t > H_{t−1}（前の足の高値を上回って引ける）。
    * 弱い版: C_t > C_{t−1}、かつ C_t が値幅の上 1/3 にある。
    * 主に H4 と D1 で使います（原文「4hや日足で確定しに来てる時」）。
  * **一定の価格以下の下髭**: 直近5本のうち3本以上で、次の2つを満たす。

### R17 レンジ中央線（レンジブレイクを放置で取る）

    * 使うのは H1 の終値です。合成クロスも終値だけなら問題ありません。
    * メモリ節約のため、1銘柄ずつ読み込んで H1 の終値だけを保存します。
  * **ペアのフィルタ**: 「基軸通貨の強さ − 決済通貨の強さ」を、IS のその差の標準偏差で割った値を z とします。
    * ロングは z ≥ θ、ショートは z ≤ −θ。θ ∈ {0.5, 1.0}。
    * 「プラマイ1」を1σと読み替えています。OANDA の計算式は非公開なので近似です。
  * **使い方**: 最良ファミリーの FX シグナルに重ねるフィルタとして検証します。
* **検証可否**: △（計算式が近似であるため）

### R19 チャートパターン

○× 表（ローソク足の本2式）のうち、○の5つを対象にします。

* **ダブルボトム**: R01 のとおりです。
* **逆三尊**（逆ヘッド・アンド・ショルダー）
  * 確定スイングロー3つ: 左肩 LS（j1）、頭 Hd（j2）、右肩 RS（j3）。
  * 頭は両肩より深い: Hd ≤ LS − h·A かつ Hd ≤ RS − h·A（h ∈ {0.5, 1.0}）。
  * 両肩の高さが近い: |LS − RS| ≤ s·A（s ∈ {0.5, 1.0}）。
  * ネックライン: j1〜j2 の最高値 N1 と、j2〜j3 の最高値 N2 を結んだ線。
  * **エントリー**: RS が確定した足（j3 + n）の終値。ただし終値がネックラインより下であること。
    * 原文は「右肩のトップでポジション形成」「ネック抜けの押し目買いは超遅い」です。
    * 頭の先端で入る版は、頭であることがその時点で分からないため**検証できません**。
  * **SL**: 左肩 LS − 0.1A（原文は「基本は左肩」）。代わりの候補は頭 Hd − 0.1A（「トップは割らない」）。
  * **TP**: ネックライン + (ネックライン − Hd)、または RR。
* **カップアンドハンドル**
  * 前提: 垂直気味の下落。D ≥ 5·A の下落が 10 本以内に起きていること。
  * その後、安値圏で R17 のレンジが N ≥ 24 本続き、幅が狭く平らであること。
  * **エントリー**: レンジの上抜け（C > RH）。
  * **TP**: 下落の始点（左肩の天井）付近。**SL**: レンジ中央線、またはレンジ安値。
  * 「左肩の安値とレンジ上限の差が大きいほど伸ばせる」は、TP の距離として自然に入ります。
* **おじいちゃんチャート**
  * 大きな下落の後、V 字で下落幅の 30〜40% を戻したところで、揉み合い（R17 のレンジ、または R05 の揃い）ができる。
  * **エントリー**: 揉み合いの上抜け。**SL**: 揉み合いの安値。**TP**: 下落の始点（全戻し）。
  * △: 定義の自由度が大きいため、格子は小さく保つこと。
* **アダムイブ**
  * 一番底が「アダム」: 1本の鋭い安値。LW ≥ 2B のピンバーで、R01 の S1 にあたる。
  * 二番底が「イブ」: 丸い底。R01 の S2 の周辺 ±0.5A の中に、B < 0.5A の小さな足が k ≥ 5 本ある。
  * R01 の部分集合として比べます。△
* **上げを探しダブルボトム**: 定義が資料にないため ×。
* **×のパターン**（フラッグ、ウェッジ、アセトラ、三角持ち合い、ダイヤモンド、三尊もどき）は、「この手法では取らない」とされているので検証しません。
* **検証可否**: ダブルボトム・逆三尊・カップは ○、おじいちゃん・アダムイブは △、上げを探しダブルボトムは ×。

### R20 日次・週次・月次の停止と撤退

* **原文**
  > 日次: 3連敗 or 資金の−3% → 当日トレード終了。週次: 資金の−5% → 当該週はトレード停止。月次: 資金の−10% → 手法の再検証フェーズ。累計 −20% → デモ口座に切り替え。リミットに達したら例外なく止める。
* **機械化**（2.7 の方式で、取引の列に重ねる）
  * 資金は固定リスク r = 1%（または 2%）の R 換算で追跡します。
  * **日次**: 3連敗、またはその日の損益が −3% → その日の残りは新規なし。
    * 日の区切りは、FX がサーバー日（NY 17:00）、BTC が UTC 日。
  * **週次**: 週の損益が −5% → その週の残りは新規なし。週は ISO 週（サーバー時刻）です。
  * **月次**: 月の損益が −10% → その月の残りは新規なし。
  * 累計 −20% は「実運用の撤退」なので、検証では到達した日付を報告するだけにします。
* **報告**
  * 重ねた場合と重ねない場合で、期待値／回、最大DD、取引数を比べます。
  * 停止ルールは、**エッジのない取引列の期待値を変えません**（取引の選び方が変わるだけ）。検証の目的は「DD を減らすか」と「実行された取引の期待値が上がるか」です。
* **検証可否**: ○

### R21 ポジションサイズと相関（1トレード1〜2%、同時2品目、合計5%）

* **原文**
  > 1トレードあたりのリスク = 資金の1〜2%以内（絶対ルール）。ロット = (資金 × リスク%) ÷ 損切り幅。10回連続損切りしても同じロット打てる管理が一番安全。同時保有は最大2品目まで、合計リスク = 資金の5%以内。
* **機械化**
  * 資金曲線を作るときの枠組みとして使います（売買シグナルではない）。
  * 複数銘柄を合成する場合: 同時保有は2銘柄まで。同じ日の同方向の円クロスは相関が高いので、1銘柄として数えます。
* **検証可否**: ○（エッジの検証ではなく、リスクの表示用）

## 4. YagamiBot v3 EA（20260303_0300_YagamiBot_v3.mq5）の正確な動作

### 4.1 実行サイクル

* OnTick が呼ばれ、**M15 の新しい足の最初のティック**（iTime(M15, 0) が変わったとき）にだけ、次を順に行います。
  1. 前回のティックにあったポジションが消えていれば、OnPositionClosed を呼びます。
     * 直近 24 時間の約定履歴から、この銘柄・マジック番号の最新の決済約定を探します。
     * 損益（手数料・スワップ込み）が負なら、日次の負け回数を +1、連敗数を +1 します。
     * 0 以上なら連敗数を 0 に戻します（建値決済も勝ち扱い）。
  2. 履歴の本数を確認します。H1 は 48 + 40 + 20 = 108 本以上、M15 は 32 本以上必要です。
  3. ポジションがあるとき:
     * **保有 H1 本数が 48 以上なら決済**（TIMEOUT）。保有本数は Bars(H1, エントリー時の H1 足の始値, 現在) − 1 です。
     * そうでなければ、**H1 トレンド（4.2）がポジションと逆なら決済**（TREND_REVERSAL）。トレンドが 0 の場合は決済しません。
     * このどちらかで決済した M15 足では、新規エントリーをしません。
  4. ポジションがなければ、PassRiskChecks（4.8）→ DetectSignal → ExecuteEntry の順に進みます。
* SL と TP は、発注時にブローカー側へ置く固定値です。**以後は一切動かしません**（建値移動・トレーリング・部分利確なし）。

### 4.2 H1 トレンド

* trend = sign(SMA12_H1[1] − SMA48_H1[1])。[1] は最後に確定した H1 足です。

### 4.3 戦略A: ダブルボトム／ダブルトップ（trend = +1 ならボトムだけ、−1 ならトップだけを見る）

1. **スイングロー（H1）**
   * p = InpSwingPeriod/2 = 5。
   * シフト i = 6〜39 について、j = 1〜5 のすべてで Low[i] ≤ Low[i±j] なら、スイングローとします。
   * 使う足はシフト 1〜44 で、すべて確定足です。右側に5本ある確定スイングなので、**先読みはありません**。
   * 新しい順に、最大6個まで集めます。
2. **ダブルボトム**
   * 集めた順（新しい順）に i < j のペアを調べ、最初に次の2条件を満たしたペアを採用します。
     * 足の間隔 ≥ 5（InpMinSwingDist）
     * |P_i − P_j| / 平均 ≤ 0.02（**価格の 2%**）
   * dbLow = 2つの安値の低い方。
3. **M15 の逆色足**: M15[1] が陽線で、実体／値幅 ≥ 0.2（十字線を除く）。
4. **スコア**
   * score = max(PA(H1), PA(M15)) で、PA は 4.5 のスコアです。
   * M15 の直近12本がレンジ（4.4）なら +1。
   * score ≥ 2（InpMinScore）が必要です。
5. **SL**: min(dbLow, H1 のシフト 1〜10 の最安値)。
6. **エントリー価格の基準** currentPrice = **M15[1] の終値**。slDist = currentPrice − SL。
7. **ATR フィルタ**: 0.3 ≤ slDist / ATR14_H1[1] ≤ 4.0。**外れたら DetectSignal 全体が false を返します**。つまりその足では戦略Bも評価されません。
8. **TP** = currentPrice + 3·slDist（InpRRRatio = 3）。
* ダブルトップは上下を逆にしたものです。

### 4.4 戦略B: レンジブレイク（中央線）

1. DetectRange（M15）
   * M15 のシフト 1〜12 の最高値と最安値から、幅を求めます。
   * 幅 ≤ 1.5 × ATR14_M15[1] ならレンジとします。
   * 中央線 center = 中点。
2. trend = +1 で、currentPrice < center、かつ M15 の逆色足（陽線）があり、PA(M15) ≥ max(1, 2−1) = 1 なら、ロングです。
   * SL はレンジの安値、TP は 3R、ATR フィルタは戦略Aと同じです。
3. trend = −1 なら、上下を逆にしてショートします。SL はレンジの高値です。

### 4.5 PA スコア（7項目。調べるのは TF の [1] 足）

1. 足の色が方向と一致している。
2. ピンバー: 方向側のヒゲが実体の2倍以上、かつ値幅の 60% 以上。
3. 包み足: 実体同士で包む（前の足が逆の色）。
4. 明けの明星／宵の明星: 足 [3] の実体の 30% 以下の足 [2] の後、足 [1] が足 [3] の中点を越えて引ける。ギャップは不要です。
5. インサイドバーの上抜け: 足 [2] が足 [3] の内側（厳密）にあり、足 [1] の終値が足 [2] の高値（安値）を越える。
6. 強い実体: GetCandleStrength ≥ 5。実体が直前10本の平均実体の 1.5 倍以上で、実体／値幅 ≥ 0.1。**色は問いません**。
7. ヒゲのサポレジ: 足 [2]〜[20] のうち、方向側のヒゲがあり、かつ安値（高値）が足 [1] の安値（高値）の **±0.5% 以内**にある足が2本以上。

### 4.6 発注とロット

* 成行で発注します。約定はロングが Ask、ショートが Bid。SL と TP は 4.3・4.4 の価格です（**M15 の終値基準で、約定価格基準ではない**）。
* スプレッドが |約定 − SL| の 20% を超える場合は見送ります。
* ロット = 残高 × リスク% ÷ (SL 距離の金額)。リスクは既定で 2%、**連敗が5以上なら半分**になります。
  * ロット刻みで切り捨てた後、**最小ロットを下回れば最小ロットに引き上げます**。この場合、リスクが設定を超えることがあります。
* 保有本数の起点は、エントリー時の H1 足の始値（GlobalVariable に保存）です。

### 4.7 決済（第4.1の3と同じ）

* TP 3R、SL（ブローカー側）、48 本の H1 経過、MA12/48 の逆転の4つです。
* 3月のバックテストでは、決済の約半分が MA 逆転でした。USDJPY は 335 回中 180 回、BTC は 468 回中 231 回です。
  * **実質は「H1 の MA 交差トレンドフォロー＋ATR で上限をつけた損切り」**で、RR 3 の TP に届くのは 1〜2 割です。

### 4.8 リスク管理（PassRiskChecks）

* 日次の負け回数が 3 以上なら、新規なし。
  * キーは `Yag3Loss_YYYYMMDD`（サーバー日）で、**銘柄・マジック番号を含みません**。全チャート共通のカウンタです。
  * **連敗ではなく「その日の負けの回数」**で、−3% の条件もありません。
* 初期残高（GlobalVariable `Yagami3_InitBal`）に対する有効証拠金のドローダウンが 30% 以上なら停止します。
  * このキーも全チャート共通で、一度設定されると更新されません。
* 週の損失が週初残高の 5% 以上なら停止します。
  * 週のキーは day_of_year/7 です。**暦の週ではなく**、年ごとに週の始まりの曜日が変わります。
* 連敗が 10 以上なら停止します。

### 4.10 先読みについて

* EA 本体に先読みはありません。
  * 指標とパターンは、すべて確定足（シフト ≥ 1）で計算しています。
  * スイングは右側5本が確定したものだけです。
  * H1 は最後に確定した足を使っています。
* 偏りがあるのは Python のバックテストのほうです。
  * backtest_v3_mtf.py: エントリーした足の高値・安値を SL/TP 判定から外している（楽観側）。
  * backtest_v3.py: 日次停止が未決済の損益を使っている（先読み）。ポジションの重複もあります。
  * backtest_v3.py の `local_min` は shift(−1) を使う先読みですが、シグナルには使われていません。

### 4.11 忠実に再現する手順（R00。後続のファミリー向け）

* **時刻の扱い**
  * M15 と H1 は、サーバー時刻で M1 から作ります。BTC もサーバー時刻です（MT5 と同じ）。
  * 判定は、各 M15 足の終値の時点で行います。EA が「新しい M15 足の最初のティック」で判定するのと同じ意味です。
  * H1 の値（SMA、ATR、スイング、PA、最安値）は、終値時刻がその M15 足の終値時刻以下の H1 足から取ります。
* **シグナル**: 4.3〜4.5 を**そのまま**（バグも含めて）実装します。
  * 2% の許容幅
  * 色を問わない強い実体
  * 常に満たされるレンジ本数の条件
  * ATR フィルタで外れたときの早期終了
* **発注**
  * 見送り条件: スプレッド（2 × half_spread）が SL 距離の 20% を超える場合。
  * sl_pips = (M15 の終値 − SL)/pip、tp_pips = 3·sl_pips。
* **決済時刻**
  * TIMEOUT は、エントリー時の H1 足の始値から数えて、H1 の足が 48 本進んだ時刻です。取引のない時間（週末など）は H1 足が存在しないので、実際の H1 足を数えます。
  * TREND_REVERSAL は、エントリー後に初めて「確定 H1 足で SMA12 と SMA48 が逆転した」時刻（その H1 足の終値）です。
  * 両者の早い方を hold に渡します。
* **重ねる条件**: 日次3敗、週次 −5%、DD 30%、連敗 10（B12 のまま）。連敗5以降のリスク半減は、資金曲線のみに反映します。
* **修正版（「v3 fixed」）も並べて報告します**。修正版の変更点は次のとおりです。
  * B1: 許容幅を 0.5·ATR_H1 にする。
  * B2: R01 の条件（割らない、リバ ≥ 1A、二番底が直近10本以内に確定、現在値が dbLow + 2A 以内）を加える。
  * B5: 強い実体を色付きにする。
  * B4: ヒゲの許容幅を 0.1·A_TF にする。
  * B6: インサイドバー1本の加点を外す。

## 6. 検証できない、または裁量の項目

* Phase 0 の自己管理: 感情の状態、リベンジトレード、FOMO（乗り遅れの恐怖）。「1つでも Yes なら今日はやらない」。
* 思考の順番のうち「自分が売買したい位置を想定する」「来たらチャートの形成を待つ」。R10 の水準で一部は近似できますが、想定そのものは裁量です。
* 「チャートはフラクタル構造の組み合わせ。組み合わせで派生する形を想定する」。
* 「分かりやすいチャートパターンほど騙しが来る」。「分かりやすさ」の定義がありません。
* 大陽線の「ライトセーバー／倍戻し」。ダイヤモンドの頂点でのショート。
* 上げを探しダブルボトム（定義が資料にない）。
* 建値ストップの例外の「割りそうな時」の判断（R15 は近似のみ）。
* 「適正価格 = 実体、ミスプライス = ヒゲ」（概念）。
* 「陰陽は体感 70:30」の「体感」の部分。R08 で頻度を測ることはできますが、本人がどの場面を 70:30 と感じるかは再現できません。
* 後乗りの「下落角度が変わる」（R08 は近似）。
* 通貨強弱の OANDA チャートの正確な計算式（R18 は近似）。
* 「レンジが得意な人はレンジだけ」「勝てないなら触るな」「ノリでエントリー」などの心構え。
* 資金管理3手法（フルレバ出金法、複利、ローレバ）の選択。月次 −10% での再検証や、デモ20トレードでの復帰などの手続き。
* 税務（税引き後 PF は算数で換算できるだけ）。
* バルサラの破産確率表（結果から計算するもので、ルールではない）。
