# index_trend_hold: 株価指数CFD・金のトレンドフィルター付き長期保有

再現: `python scripts/research_index_trend_hold.py`（ログ済みのIS試行を再利用して最終表を表示。`--fresh` で探索からやり直し、`--save` で equity/trades parquet を保存）
戦略コード: `fxlab/strategies/index_trend_hold.py`（`IndexTrendHold`）
試行ログ: `reports/trials/index_trend_hold.jsonl`（87試行、すべてIS 2005-2014のみ）

## 結論

**判定: marginal（本番採用は推奨しない）**

* 選ばれた設定（12か月モメンタムがプラスの間だけ買い持ち）は、IS・OOS・先物データの2期間・コスト2倍の**すべてでプラス**でした。ただし水準がとても低く、統計的にも有意ではありません。
  * 1%リスク・50万円スタートで CAGR は IS 3.6%、OOS 0.8%、先物プレ 1.6%、先物OOS 4.2%。Sharpe は 0.40 / 0.155 / 0.36 / 1.08 です。
  * Deflated Sharpe は 0.002（87試行）。
* 利益の源泉は「アルファ」ではなく**株式・金のリスクプレミアム（ベータ）**です。トレンドフィルターは長い下げ相場を避けます（2008年、1996-2002年の金の下落、2000-2003年）が、V字型の急落（2015-16年、2018年、2020年）では損をします。
  * バイ＆ホールドより良かった期間: IS、先物プレ（1983-2004）、先物OOS（2020-2024）。悪かった期間: OOS（2015-2020/05）。
* 採用基準のうち満たしていないもの:
  * (1) DSR が低い。
  * (5) 利益の集中。IS利益の大半は2013年（+27.7%）です。2013年を除くと IS Sharpe は 0.17 まで下がります。NAS100 1銘柄で IS 純損益の40%を占めます。
* **CFDの金利コスト（ロング = 政策金利 + 2.5% − 配当）が大きい**です。IS ではスワップが総利益（純損益 + スワップ + 手数料 = 160,085円）の27%、手数料が9%を占めています（下の表）。
* 1%リスクで、損切りを広く取る（5×ATR）と平均エクスポージャーは約0.5倍です。そのため 50万円→1億円 の複利目標には**リターンの桁が足りません**。リスクを上げればドローダウンも比例して増えます（ISの最大DDは1%リスクで22%）。

## 売買ルール（MT5 EA で実装可能）

* 銘柄: US500, NAS100, US2000, JPN225, UK100, FRA40, AUS200, XAUUSD。日足（サーバー時間、NY17時締め）。
* 各日足の確定時（足 t）に `mom = Close[t] / Close[t-252] − 1` を計算する。
* **エントリー**: ノーポジションで `mom > 0`（かつ履歴が260本以上）なら、次の足の始値で買う。
  * 約定は 01:00（サーバー時間）の足。ロールオーバー時間は避ける。欧州指数はその日の最初の取引時間の足。
  * 損切り = 約定価格 − 5 × ATR(20)。ATR は日足 iATR（TR の単純平均）の足 t の値。
  * ロット = 残高 × 1% ÷（損切り幅 × 1ロット1ポイントの円価値）。ロット単位で切り捨て、最小ロット未満なら見送る。
* **決済**: 買い保有中に日足確定で `mom ≤ 0` になったら、次の足の始値（同じタイミング）で決済する。
* 損切りは固定。トレーリング・利確・時間決済はない。損切りにかかった後も、次の日足確定で `mom > 0` なら新しいロットと損切りで再エントリーする。
* 買いのみ。1銘柄1ポジション、同時保有の合計初期リスクは8%まで（エンジン共通の制約）。

パラメータ: `filter="mom", mom_n=252, stop_atr=5.0, atr_n=20, max_hold=0, side="long", rebalance="daily", warmup=260`（`band_atr / vol_max / dd_atr / trail_atr` は 0 = 不使用）

## 検証方法

* 探索は IS（2005-01〜2014-12、OANDA）だけで行い、87試行すべてをログに記録。段階は以下のとおり。
  * A: フィルターの種類と長さ（B&H、SMA/EMA 100-250、モメンタム 126/189/252、SMA&MOM）。
  * B: 追加条件（月1回判定、ヒステリシス帯、ボラ比 ATR20/ATR100、1年高値からの下落幅、ロング/ショート）。
  * C: リスク設定（損切り 3/5/8 × ATR20/ATR100、再サイズ間隔 max_hold 0/65/260、トレーリング）。
  * D: 追加条件の組み合わせ。条件を満たす候補がなく、該当なし。
  * E: 金を除く7指数。
  * F: 候補3つの近傍でプラトー検定。
* **2つの口座規模で評価**した。
  * 50万円口座では、指数の最小0.1ロット・金の最小0.01ロット（=1オンス ≒ 口座の3割の建玉）のために、広い損切りのエントリーが多く見送られる（`below_min_lot`）。
  * そこで各試行を「標準（50万円・1%リスク）」と「5,000万円・1%リスク（ロットの丸めが効かない）」の両方で走らせた。
  * ISスコア = 両方の IS Sharpe の平均。取引数が少ない試行は除外（50M で150回未満、または500kで100回未満）。
* 選択はプラトー検定の中央値で機械的に行った（`MOM252|stop5xATR20|mh0`）。その後に OOS・先物・コスト2倍を1回だけ評価した。
* ISの主な発見（Sharpe は 500k / 50M の順）:
  * B&H（損切り5×ATR20、年1回再サイズ）は 0.28 / 0.28。
  * フィルターの最良は EMA250 0.37 / 0.37、MOM252 0.34 / 0.34（年1回再サイズ時）。短いSMA/EMA（100-200）は B&H 以下だった。
  * 追加条件は**どれも改善しなかった**。
    * ボラ比フィルター（<1.3 / <1.6）はすべて悪化。
    * 高値からの下落幅での撤退（8/12 ATR）は悪化または同等。
    * ヒステリシス帯は SMA のみ小幅改善、EMA は悪化。
    * 月1回判定は取引数不足。
    * ロング/ショート（ショートは配当 + 2.5% を払う）は大きく悪化（MOM252: 0.17 / 0.19）。
  * **再サイズしない（max_hold=0）方が良かった**（MOM252: 0.40 / 0.41。年1回で 0.34、四半期で 0.24）。再エントリーのたびに損切りが「現在値 − 5ATR」に引き上がり、事実上のトレーリングストップになって上昇トレンドを削るため。第1波の結果と同じ。

* スポットCFDのロングは「政策金利 + 2.5% − 配当利回り」を払います（例: 2006-07年の US500 は年 -5.6〜-5.7%、2010-14年は約 -0.5〜-0.8%）。
* 先物データは価格に金利・配当が含まれ、ブローカーのマークアップ -2.5% だけを追加しています。
* エンジンはスワップを「エントリー年の金利 × エントリー時の想定元本」で保有期間全体に掛けます。この戦略は数年保有することがあるため、日ごとに「その年の金利 × 前日終値の想定元本」で計算し直しました（スクリプトの `swap_exact`）。実際のコストは年0.1〜0.2%多くなります。上の成績表はエンジンの値のままです。
* 金利が高い局面（2023-26年の米金利3.6-5.1%）では、米国指数CFDのロングは年約5-6%の金利を払います（instruments.py の金利表で 2023年 -6.0%、2024年 -6.3%、2025年 -5.5%）。長期保有の利回りの大半が消えます。

## 実装上の注意

* **最小ロット**: 50万円・1%リスク・5ATR損切りでは、金（最小0.01ロット = 1オンス）は IS で一度も建たず、UK100・FRA40 と、価格が上がった後の NAS100 もしばしば見送りになります。実際に取引できるのは4〜5指数です。Titan FX の指数CFDの契約サイズ・最小ロットは `instruments.py` の仮定（1ロット = 指数×1、最小0.1）です。MT5 の仕様画面で必ず確認してください。契約サイズが10倍なら、ほぼ全銘柄が建てられません。
* 米国指数は 01:00 の足で約定します。欧州指数は日足確定後の最初の取引時間の足（サーバー時間 09-10時）です。
* 損切りは常に設定します（5×ATR20）。ナンピン・グリッド・マーチンゲールはありません。

## 主なリスク

1. 利益の集中（2013年、NAS100）と、有意でない統計（IS t = 1.32、OOS t = 0.79、DSR 0.002）。
2. OOS 2015-2020 ではバイ＆ホールドに負けた。12か月モメンタムは急落→V字回復の相場に弱い。
3. CFDの金利コスト。金利上昇局面ではロング保有の期待値がほぼゼロになる。
4. 低いリターン水準。1%リスクで CAGR 1〜4%。増やすにはリスクを比例して上げるしかなく、ドローダウンも比例する。
5. 窓開け（1987年型）は損切りを飛び越える。
6. 小口口座では最小ロットのため分散が効かない。
