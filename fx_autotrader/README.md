# FX自動売買システム（Titan FX / MT5 / 円口座）

元金50万円から段階的に1億円を目指す、という依頼に対して、次の3つを作りました。

1. **検証基盤**：実データのバックテストエンジン（Python）
2. **検証結果**：戦略11系統・1,383通りを検証し、生き残ったのは1本
3. **MT5用EA**：Titan FX で動く自動売買プログラムと、その運用計画

## 結論（最初に読んでください）

* **採用できた戦略は「gotobi（五十日）」の1本だけ** です。
  * 日本の五十日（5・10・15・20・25日・月末）の **09:55 JST（仲値公示）直後にドル円を売り、15:00 に決済** します。
  * 過去15年（2005〜2020）の成績（リスク1%/回）
    * 検証期間：年率 6.8%、Sharpe 1.71
    * 未使用期間（OOS）：年率 3.3%、Sharpe 0.67
  * 仕組み（仲値に向けたドル買いの反動）は、OOS でも統計的に確認できました。
  * 一方で、利益は少数のイベント日に偏っています。約定が1分遅れるだけで成績は大きく落ちます。
* **トレンドフォロー、逆張り、ブレイクアウト、通貨強弱、キャリー、株価指数**など、他の10系統は、実際の取引コストを入れると、未使用期間でマイナスか、ほぼゼロでした（`docs/RESULTS.md`）。
* **50万円を運用益だけで1億円にするのは、現実的ではありません。**
  * 20年で1億円に届くのは、毎月約30万円を入金し続けた場合です（`docs/STAGED_PLAN.md`）。
  * リスクを上げて届かせようとすると、少し期待値が下振れしただけで、資金の大半を失う確率が高くなります。
* 2020年6月以降の gotobi は、分足データがなく未検証です。**本番前に必ず次の2つを行ってください。**
  1. Titan FX のデータで MT5 テスター検証（2020〜2026）
  2. 3か月以上のデモ運用

  （手順は `docs/EA_MANUAL.md`）

## 10万円 → 100万円 の短期チャレンジ（ハイレバ・全損許容）

`docs/CHALLENGE_10X.md` を参照してください。
* 同じ gotobi のルールで、1回のリスクを30〜100%に上げる設定です。プリセットは `mt5/presets/` にあります。
* 100万円に達すると自動で全決済・停止します。
* 10倍に届く確率は、期間とリスクに応じて約10〜20%です。ほぼ全損の確率は約10〜60%です。

## 使い方（Python 側）

```bash
pip install -r requirements.txt
python -m pytest -q tests                  # テスト
python scripts/portfolio_candidates.py     # 候補3系統の単独・組み合わせ成績
python scripts/staged_plan.py              # 段階計画のモンテカルロ
python scripts/export_expected_trades.py   # EA と照合するための期待トレード一覧
```

1分足から足データを作り直すには、公開データ（github.com/FutureSharks/financial-data）を取得してから `python scripts/build_data.py` を実行します。

## 検証の方法（要約）

* データ
  * OANDA 1分足（2005〜2020、FX15ペア＋金＋株価指数7）
  * FRB の日次為替（1971〜2026）
  * 先物の長期データ（1975〜2024）
* 判定の手順
  1. パラメータは **2005〜2014年だけ** で選ぶ
  2. 2015〜2020年の未使用期間と、1976〜2004年・2020〜2026年の独立データで確認する
  3. コスト2倍、近傍パラメータ、特定の年・銘柄を除いても残るか確認する
  4. 別のエージェントが反証を試みても残ったものだけを採用する
* コストは Titan FX ブレード口座に合わせています。
  * 手数料 720円/ロット
  * スプレッドは公表平均より広め
  * スワップは実測に合わせてマークアップ 2.5%
  * 損切り時のスリッページ
* バックテストエンジン自体も2回監査し、見つかったバグ15件を修正済みです（未来参照、コストの漏れ、期間末の計上ミスなど）。

## 追加で決めてほしい条件

以下が決まると、計画をより正確にできます。

1. **口座タイプと MT5**
   * 推奨はゼロ・ブレード口座（MT5）です。
   * スタンダード口座だと往復コストが約0.3pips増え、gotobi の期待値の1〜2割が消えます。
2. **運用環境**
   * gotobi は 09:55:00 ちょうどの約定が命です。
   * Titan FX の VPS（ニューヨーク）か、NTP で時計を合わせた Windows VPS で24時間動かせますか。
3. **毎月の入金額**
   * 1億円への到達は、ほぼ入金額で決まります。
   * 例：月10万円なら30年で5,000万〜1億円、月30万円なら20年で約1億円。
4. **許容できる最大ドローダウン**（例：10%、20%）
   * リスク%と停止ルールの設定が決まります。
5. **他の所得（給与など）の金額**
   * 海外業者の利益は総合課税（最大約56%）です。
   * 他の所得によって税引後の成長率が大きく変わります。
6. **何年かけてよいか**
   * 「時間がかかってもいい」とのことでしたが、20年・30年などの目安があると計画を具体化できます。
7. **業者の分散・国内業者への移行**
   * Titan FX は金融庁の警告リストに載っており、信託保全もありません。
   * 残高が大きくなったら（目安300万〜1,000万円）、出金や分散をしますか。
   * 同じ EA は国内の MT5 業者（分離課税20.315%）でも動きます。
8. **株価指数・金などの CFD**
   * 検証しましたが不採用でした。今後も FX 以外を候補に含めますか。
