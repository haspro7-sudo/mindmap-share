# 段階計画：50万円 → 1億円

## 最初に正直な結論

* 検証で残った戦略は **gotobi 1本**です。期待値は年 **約3〜6%（リスク1%/トレード時）** です。
* この戦略で **50万円を運用益だけで1億円にする** には、リスクを極端に上げる必要があります。
  * 下の表のとおり、それでは期待値が少し下振れしただけで、**資金の大半を失う確率が非常に高く**なります。
* 1億円に届くかどうかは、**毎月の入金（積立）額でほぼ決まります**。
  * 20年で1億円を目指すなら、毎月 約30万円の入金が必要です。
  * そのうえで運用益が 2,000〜3,000万円程度を上乗せする、というのが現実的な姿です。
* 計算は `python scripts/staged_plan.py`（結果は `reports/staged_plan_mc.md`）。
  * 3,000パスのブートストラップで、税金（総合課税）を毎年3月に口座から支払う前提です。

### リスクを上げたら？（入金なし・固定リスク・30年）

| 1トレードのリスク | 想定 | 20年で1億 | 30年で1億 | 最大DDの中央値 | DD30%超の確率 |
|---|---|---|---|---|---|
| 3% | バックテスト通り | 0% | 8% | 20% | 4% |
| 5% | バックテスト通り | 22% | 95% | 32% | 62% |
| 8% | バックテスト通り | 89% | 100% | 47% | 100% |
| 5% | 期待値が半分 | 0% | 3% | 46% | 99% |
| 8% | 期待値が半分 | 5% | 30% | 65% | 100% |

* バックテストがそのまま再現されれば、5〜8%のリスクで1億円に届きます。
* しかし期待値が半分になっただけで、**大きなドローダウンを抱えたまま目標に届かない** 結果になります。
  * 選択バイアスや執行の劣化を考えると、期待値の半減は十分ありうる想定です。
* 未来の成績は、バックテストより悪いと考えるのが普通です。**本計画ではリスク上限を1.25%とします。**

## 段階

### Stage 0：検証とデモ（資金は入れない。目安 3〜4か月）

1. **最新期間の検証**
   * MT5 のストラテジーテスターで、Titan FX の USDJPY を使って 2020年6月〜2026年9月を検証します（手順は `docs/EA_MANUAL.md`）。
   * この期間は研究用の分足データがなく、**gotobi の初めての検証**になります。
   * 次のどちらかに当てはまれば、gotobi は**不採用**です。**このシステムは使わない**という結論になります。
     * 平均R（手数料・スワップ込み）が 0 以下
     * 五十日の 09:55→10:05 の平均値動き（売り方向）が +1.0pip 未満
2. **EA とバックテストの一致確認**
   * `reports/expected_trades.csv` の gotobi 166件（2018-01〜2020-05）と比較します。
   * 合格基準：日付と方向は100%一致、エントリー価格は95%以上が1pip以内。
3. **デモ口座（Titan FX Zero ブレード）でのフォワードテスト**
   * 3か月以上、gotobi 30回以上。2026/10/30 を含めてください。この日は米欧のサマータイムがずれる週で、サーバー時計の方式が確認できます。
   * 合格条件（1つでも不合格なら本番に進まない）：
     * 95%以上の日で 09:55:00〜09:56:00 JST に約定
     * 約定時刻の中央値が 09:55:03 以内
     * 09:55:00 の仲値に対するエントリーの不利約定が平均 0.7pip 以下
     * 往復の総コスト（スプレッド＋スリッページ＋手数料720円/ロット）が 2.0pips 以下
     * 発注時のスプレッドが 0.7pip 以下の日が75%以上

### Stage 1：本番 50万円、gotobi 0.5%

* 1回のロットは 0.05 前後です（損切り幅 約45〜50pips）。
* 最初の20回は、執行品質の確認期間として扱います。

### Stage 2：リスク 1.0% に上げる条件（すべて満たすこと）

* 本番の gotobi が140回以上（約2年）で、平均R が +0.02 以上
* 直近120日の「09:55→10:05 の値動き」の平均が +1pip 以上
* 本番の執行コストとモデルの差が 0.3pip 以内
* 資産が最高値を更新中
* 直近6か月に一時停止・停止がない

### Stage 3：上限 1.25%

* 1.0% で24か月以上運用し、実現 Sharpe 0.5 以上、最大DD 10% 未満の場合のみ上げます。
* **gotobi 単独のあいだは 1.25% を超えないでください。**

### リスクの変え方

* 入力 `InpGotobiRiskPct` を手で変えてください。
* 残高に応じてリスクを自動で上げる設定（`InpStages`）は **"0:1.0" のまま** にします。
  * 自動にすると、成績ではなく入金で段階が進んでしまうためです。
* 入金すればロットは残高に比例して自動で増えます。

## 停止ルール（EA の入力にも反映済み）

「R」は1トレードのリスク額（リスク0.5%なら口座の0.5%）です。

| 条件 | 動作 |
|---|---|
| 資産のピークから **リスクの8倍** の DD（0.5%なら4%） | 新高値までリスク半減（EA が自動、`InpThrottleDDPct`） |
| 評価額がピークから **リスクの12倍**（0.5%なら6%） | EA が全決済して停止。デモに戻り全面的に見直す（`InpHaltDDPct`） |
| 本番開始からの累積 -8R、または gotobi の DD 10R 以上 | 一時停止して見直す |
| 直近142回の損益合計 -7R 未満、かつ値動き指標 +1pip 未満 | gotobi を不採用に |
| **値動き指標**：五十日の 09:55→10:05 の平均（売り方向）が、60日時点で +0.5pip 未満 | 一時停止（最も早く異常に気づける指標） |
| 同じ指標が120日時点で 0 未満 | 不採用 |
| 直近20回で約定時刻の中央値が 09:55:03 より遅い、不利約定の平均が 0.7pip 超、スキップが25%超 | 一時停止 |
| 直近30回の往復総コストが 2.5pips 超 | 不採用（コストが +1pip で期待値の半分が消える） |
| サーバー時計のGMTオフセットが想定と違う日 | その日は見送り（EA が自動） |
| 直近12か月のリターンが リスクの -6倍 未満 | リスク半減 |

**リスクを上げる前に** `InpThrottleDDPct` と `InpHaltDDPct` もリスクに比例して上げてください。1.0%なら 8% と 12%、1.25%なら 10% と 15% です。

## 資金の節目ごとにすること

| 残高 | すること |
|---|---|
| 50万〜100万円 | Stage 1 のまま。まず執行品質と値動き指標を確認する |
| 100万円〜 | carry の条件を満たす年が来たら（前年の金利差が4%以上のペアが出たら）、carry を 0.5% で有効化できる（`InpCarryOn`） |
| 300万円〜 | 利益の一部を定期的に出金する。**業者リスク対策**（Titan FX は信託保全なし・金融庁の警告リスト掲載） |
| 年間利益 500万円超 | 海外業者の総合課税は国内業者（分離課税20.315%）より不利になる。税理士に相談する |
| 年間利益 800〜1,000万円 | 法人化を検討する。同じ EA を **国内の MT5 対応業者**（レバレッジ25倍）で動かすのも選択肢。gotobi は実効レバレッジが低く、1億円規模でも数倍なので25倍で足りる |
| 国外資産 5,000万円超（12/31時点） | 国外財産調書の提出義務（翌年6/30まで） |
| 1,000万円〜 | 1社に全額を置かない。複数の業者・口座に分けるか、必要証拠金以外は国内に戻す |

## 入金（積立）について

* 20年で1億円に届く確率を半分以上にするには、上の表のとおり **毎月30万円前後** の入金が必要です。
* 入金はいつでも構いません。EA のドローダウン判定は入出金の分を自動で補正します（v1.10）。
* 入金しても、`InpGotobiRiskPct` は変えないでください。
