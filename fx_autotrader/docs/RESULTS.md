# 検証結果のまとめ（最終版・監査済みエンジン）

## 結論

* 11系統の戦略（試行 1,383 通り）を、IS→OOS→独立データ→コスト2倍→独立エージェントによる反証の順で検証しました。
* **合格は0本**でした。条件付きで残ったのは **gotobi（五十日・仲値後のドル円売り）** の1本だけで、判定は「弱いが本物」です。
* **1本だけ**で運用する前提なら、年利の目安はリスク1%で約3〜6%、リスク0.5%で約1.5〜3%です。
* **50万円を運用益だけで1億円にする現実的な道筋は、見つかりませんでした**。数字は `docs/STAGED_PLAN.md` を参照してください。

## gotobi の詳細（採用する唯一の戦略）

* **ルール**：日本の五十日（5・10・15・20・25日・月末。休日なら前営業日）の **09:55:00 JST にドル円を成行売り**。損切りは約定価格＋日足ATR(14)×0.5（前日確定値）を同時に置く。**15:00 JST に決済**。12/25 は見送り。
* **仕組み**：輸入企業のドル買いで、ドル円は 09:55 の仲値公示に向けて上がりやすい。公示後はその反動で下がる、とされています。
* **数字**（リスク1%、コスト込み）
  * IS 2005-2014：Sharpe 1.71、年率 6.8%、最大DD 6.3%、711回、平均 +0.098R（t=5.5）
  * OOS 2015-2020/05：Sharpe 0.67、年率 3.3%、最大DD 7.0%、380回、平均 +0.050R（t=1.56）
  * 1トレードの期待値は約 +2〜4 pips。損切り幅は約45〜50pips、往復コストは約1.5pips。
* **弱点**
  * OOS利益の87%は上位5日（2016/6/24 Brexit、2016/4/28 日銀、2015/6/10 黒田発言など）。これを除くと t=0.6。
  * **エントリーが1分遅れると Sharpe 0.67→0.44、5分遅れで 0.15**。約定の速さが生命線です。
  * コストが1pip増えると OOS Sharpe 0.36、2pip増えるとほぼゼロ。
  * 2020年6月〜2026年9月は分足データがなく未検証です。**本番前に Titan FX のデータで検証してください**（`docs/EA_MANUAL.md`）。
  * 期待値はイベント日に偏るため、何か月も横ばいが続くことがあります（OOSで最長185トレード高値を更新しない期間）。

## 検証の過程で見つけて直したエンジンのバグ（監査2回・計15件）

* 終値しかない FRED データでは損切りが刺さりにくく、成績が過大になっていた → 過去データからヒゲを合成（較正済み）
* 逆指値エントリーの同じ足の中の順序を1分足で判定するように修正
* 手数料とスワップを平均Rなどのトレード統計に含めていなかった
* 日足の約定がロールオーバー直後（スプレッド拡大時）になっていた → 01:00 に変更（EAも同じ）
* IS期間末の建玉がOOSの値動きで評価されていた。期間末日の損益の二重計上もあった
* 手数料を実額（720円/ロット）に、スワップのマークアップを実測に基づき 2.5% に変更 など

詳細は `docs/RESEARCH_PROTOCOL.md` と git 履歴を参照してください。

## 各レポートについての注意

`reports/<系統>.md` は各研究エージェントが書いたもので、数値の一部はエンジン修正**前**の値です。スワップのマークアップ 1.5%、グロスR、ロールオーバー約定などが該当します。**最終的な数値は、このファイルと各検証の結果を正としてください。** 再計算は `python scripts/portfolio_candidates.py`（候補3系統）と各 `scripts/research_*.py` で行えます。
